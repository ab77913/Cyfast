# CyFAST Connect W1
W1 provides feature-flagged, outbound Windows desktop automation. It manages enrolled Windows nodes, scoped application profiles, interactive UIA sessions, commands, and protected evidence.

Enable the operator UI only for development with `VITE_WINDOWS_AUTOMATION_ENABLED=true`; enable services separately with `WINDOWS_AUTOMATION_ENABLED=true`.

Read [installation](W1_INSTALLATION.md), [API](W1_API.md), [testing](W1_TESTING.md), and [troubleshooting](W1_TROUBLESHOOTING.md). W1 does not provide desktop streaming, WebRTC, arbitrary shell execution, or an auto-updater.
